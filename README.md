# WeatherNow Dashboard

A beginner-friendly weather dashboard built with HTML, CSS, and JavaScript.
![shows the city weather forecast for nairobi](https://github.com/markcliff6064/week-3-weather-dashboard/blob/e8d62b5bec2285d68ce08c0e7ecb4eccd18b3328/2.png)
![shows the city weather forecast new york](https://github.com/markcliff6064/week-3-weather-dashboard/blob/e8d62b5bec2285d68ce08c0e7ecb4eccd18b3328/1.png)
## Features

- Search for cities around the world.
- View current weather and a five-day forecast.
- Switch between Celsius and Fahrenheit.
- Save the last 10 searched cities.
- Display loading messages and handle errors.
- Save weather data for offline use.
- Responsive layout for desktop and mobile.

## Technologies

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- localStorage
- Git and GitHub

## How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Get an API key from https://openweathermap.org/api.
4. Add your API key to `js/app.js`.
5. Open `index.html` using VS Code Live Server.

An internet connection is needed to fetch live weather data.

## Project Structure

- `index.html` — Page structure
- `css/styles.css` — Page styling
- `js/app.js` — Weather requests and dashboard features
